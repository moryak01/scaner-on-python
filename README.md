### 🚩 Флаги и параметры

* **`-t, --target`** *(Обязательный)* - Целевой IP-адрес или домен.
* **`-p, --ports`** - Порты для сканирования. Поддерживает одиночные (`80`), перечисленные через запятую (`22,80`) и диапазоны (`1-1000`).
* **`-T, --threads`** - Количество потоков. Чем больше, тем быстрее сканирование.
* **`--timeout`** - Таймаут подключения в секундах.
* **`-h, --help`** - Показать краткую справку по использованию.

* **` Пример - python scaner1.py -t example.com -p 1-1000 -T 500 `**
